## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.

- Recent GitHub Blog and Changelog stories worth watching.
- Agentic/automated GitHub workflows, including community examples from Awesome Copilot.

## Agentic Copilot workflows (Awesome Copilot)

Awesome Copilot (awesome-copilot.github.com/workflows) is a community-curated
gallery of ready-to-use GitHub Copilot agentic workflow examples — things like
automated issue triage, PR review helpers, and scheduled repo maintenance
tasks built with GitHub Actions + Copilot. It's a good next step for readers
who already understand Copilot basics and want to see practical, runnable
workflow patterns rather than just IDE/CLI usage.

*Source: awesome-copilot.github.com/workflows*
